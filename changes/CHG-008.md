# CHG-008

## Summary

Add a backend-only Gemini exam-generation scaffold for course lesson and final exams, using compact requests suitable for low-cost usage and keeping secrets out of frontend code.

## Reason

The product direction now needs an implementation path for AI-assisted exam generation across both student course exams and company preview exams, while still keeping request size small enough for free-tier testing and avoiding direct secret exposure in the client.

## Impacted units

- Course assessment generation
- Student lesson and final exam flow
- Company preview lesson and final exam flow
- Backend configuration and secret handling

## Decision

Introduce backend-only Gemini configuration via environment variables, add a shared Gemini exam-generation service that produces compact JSON-only requests, and keep the initial change at scaffold level until the runtime assessment-attempt flow is updated to support generated question sets safely.
