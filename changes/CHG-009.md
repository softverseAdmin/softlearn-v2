# CHG-009

## Summary

Add persisted student course ratings and review sections to the learning experience, and use those real aggregates in student course cards and course detail screens.

## Reason

The student course experience currently relies on placeholder rating data and does not provide a real place for learners to submit feedback while studying. The product now needs authentic course review data that can be surfaced consistently on lesson pages, course detail pages, and course catalog cards.

## Impacted units

- Student course catalog
- Student course detail
- Student lesson experience
- Backend course APIs and persistence
- Demo course review flow

## Decision

Introduce a backend `CourseReview` model with one review per student per course, expose review aggregates and recent review data through student course endpoints, add a student review submission endpoint gated by enrollment, and render reusable ratings-and-reviews UI in the student lesson and course detail flows while updating course cards to use the real aggregates.
