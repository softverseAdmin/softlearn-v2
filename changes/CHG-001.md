# CHG-001

## Summary

Construction sequencing exception for early U1 repository and API baseline work

## Reason

Repository bootstrap and the base API contract were documented before repository tracking was fully synchronized with the completed inception units and before the earlier U1 authentication units were scaffolded. This exception is being recorded explicitly so the repository history reflects the real delivery order instead of silently rewriting state.

## Impacted units

- U1-1-project-initialization
- U1-2-authentication-core
- U1-3-role-based-access-control
- U1-4-base-api-structure
- Project planning records

## Decision

Keep U1-1-project-initialization and U1-4-base-api-structure as completed documented units. Treat U1-2-authentication-core as the current next active unit, keep U1-3-role-based-access-control pending behind it, and record this sequencing exception rather than backfilling false completion for skipped prerequisites.

Accepted
