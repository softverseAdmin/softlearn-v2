# CHG-005

## Summary

Persist all student profile sections in the backend database instead of splitting core data and browser-only local state.

## Reason

The accepted baseline already includes student profile management, but the implemented experience shipped with several profile sections saved only in local browser storage. That breaks cross-device continuity and creates inconsistent profile behavior, so the persistence scope needs to be explicitly expanded.

## Impacted units

- U2-3-student-profile-basic
- U2-5-student-profile-education
- U2-6-student-profile-experience
- U1-8-base-ui-layout

## Decision

Store student about text, profile images, certificate records, education extra details, and experience skill tags in the Django data model and expose them through authenticated student profile APIs. The React profile UI should use those APIs as the source of truth while preserving the current interaction patterns.
