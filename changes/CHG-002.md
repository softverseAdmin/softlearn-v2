# CHG-002

## Summary

SaaS UX redesign for roadmap-based learning, assessment, and hiring pipeline

## Reason

The accepted baseline defined a functional dashboard, but the product direction has now shifted toward a professional SaaS UX centered on roadmap learning, assessment gates, premium progression, and hiring outcomes. Without a tracked change record, the redesign would silently alter the accepted construction baseline for dashboard, auth, roadmap, and mobile experience units.

## Impacted units

- U17-1-student-dashboard
- U17-2-company-dashboard
- U17-3-admin-dashboard
- U1-2-authentication-core
- U14-5-performance-tracking
- New redesign units beginning with U20-1-student-dashboard-redesign

## Decision

Introduce a redesign track that reworks the application UX into a modern SaaS flow focused on learning -> assessment -> hiring. The redesign will be delivered as separate development tasks rather than silently overwriting the original baseline, starting with U20-1-student-dashboard-redesign and continuing with later dashboard, auth, roadmap, and mobile redesign units.
