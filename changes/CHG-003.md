# CHG-003

## Summary

Public root page redesign for a marketing-style landing experience

## Reason

The accepted baseline already established the public shell and basic landing route, but the product now needs a stronger public entry experience that better communicates learning, preparation, and hiring value at first view. Recording this change avoids silently replacing the earlier minimal landing presentation with a more opinionated visual direction.

## Impacted units

- U1-6-routing-and-navigation
- U1-8-base-ui-layout
- Public root landing page implementation in `frontend/src/pages/LandingPage.tsx`

## Decision

Adopt a richer marketing-style root page with branded navigation, hero content, platform metrics, feature highlights, and audience-focused sections while keeping the accepted React + Vite stack, public/auth route split, and privacy-aware product positioning unchanged.

Accepted
