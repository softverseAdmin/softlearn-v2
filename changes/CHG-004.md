# CHG-004

## Summary

Student work history and resume document management workspace redesign

## Reason

The accepted baseline already covers structured experience records and resume metadata, but it does not provide a dedicated production-style document workspace with upload UX, preview, file management, and AI-extracted insight presentation. Recording this change avoids silently expanding the student profile baseline with a richer SaaS document-management experience.

## Impacted units

- U2-6-student-profile-experience
- U2-8-student-resume-management
- U1-6-routing-and-navigation
- U1-8-base-ui-layout

## Decision

Add a protected student-facing work history document workspace that supports frontend-managed upload validation, document preview, file list management, profile links, and mock AI insight presentation while keeping backend integration cleanly separated for later AWS-compatible implementation.

Accepted
