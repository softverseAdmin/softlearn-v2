# Unit lifecycle

## Sequence

1. Create the unit folder from `templates/unit`.
2. Complete `functional-design.md`.
3. Complete `nfr-requirements.md`.
4. Complete `nfr-design.md`.
5. Complete `infrastructure-design.md`.
6. Prepare `code-generation.md`.
7. Review the unit outputs.
8. Open a pull request for the unit.

## Notes

- Update `unit-state.md` at each meaningful stage completion.
- Record dependencies, scope boundaries, risks, and open questions before implementation.
- If a unit changes baseline behavior, create or link a CHG record.
