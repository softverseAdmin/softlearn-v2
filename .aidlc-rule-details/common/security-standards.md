# Security standards

## Required principles

- Least privilege
- Authentication before protected features
- Authorization checks on protected actions
- Sensitive data protection
- Student privacy by default
- Audit logging for company access to student data
- Input validation
- Meeting URL validation
- Secure file-upload rules if resumes are added later

## Repository implications

- Security design must precede code generation for protected capabilities.
- Privacy-sensitive features need explicit review notes and test planning.
