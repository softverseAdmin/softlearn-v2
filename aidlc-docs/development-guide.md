# Development guide

## Standard workflow

1. Pick one AI-DLC unit.
2. Create or switch to the appropriate branch.
3. Complete the required unit documents in order.
4. Update the unit state.
5. Run `./scripts/aidlc-check.sh`.
6. Open a pull request with the AI-DLC template.

## Practical guidance

- Keep one unit in progress at a time when practical.
- Use CHG records for baseline changes.
- Avoid implementation work before inception decisions are complete.
- Keep privacy, access control, and matching explainability visible in every relevant unit.
