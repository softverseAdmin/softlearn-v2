# Inception v1 requirements

## Purpose

Define the baseline platform requirements for the AI-DLC Learning & Career Matching Platform before technology selection and implementation.

## Actors

- Student
- Company user
- Admin

## Student requirements

- Register and log in
- Manage profile information
- Manage skills
- Manage language level
- Enroll in courses
- Learn lessons
- Take exams
- View exam results
- Prepare for exams
- Search vacancies
- Apply to vacancies
- Manage interview schedules
- Control privacy of profile and results

## Company requirements

- Register and log in
- Manage company profile
- Post vacancies
- Define required skills and language levels
- View matched students
- Review allowed student profile data
- View allowed exam results
- Shortlist or reject candidates
- Schedule interviews
- Add meeting URLs

## Admin requirements

- Manage students
- Manage companies
- Manage courses
- Manage exams
- Manage vacancies
- Monitor platform operations

## Non-functional themes

- Security
- Privacy
- Scalability
- Explainable matching
- Auditability
- Maintainability

## Scope notes

- The platform supports learning and job matching in one product.
- Company visibility into student information must respect consent and access rules.
- Technology remains undecided at this stage.
