# ADR-001: Technology stack

## Status

Proposed / Pending

## Context

The platform needs a technology stack that supports AI-DLC unit-by-unit delivery, strong privacy controls, explainable matching, and scalable learning and hiring workflows. The repository must not assume a final stack until the comparison work is complete.

## Options

- Backend candidates
- Frontend candidates
- Database candidates
- Authentication candidates
- Infrastructure candidates
- AI and matching candidates

## Decision

Pending. See `technology-decision.md` for the comparison workspace.

## Consequences

- Positive consequences will be recorded after selection.
- Negative consequences and tradeoffs must be documented explicitly.

## Risks

- Premature stack choice can distort unit design.
- Delayed stack choice can slow implementation unless inception scope stays disciplined.

## Revisit date

To be set when the decision is accepted.
