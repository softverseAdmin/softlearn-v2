# Inception v1 security and compliance

## Core requirements

- Personal data protection
- Student consent management
- Company access audit
- Role-based access
- Secure authentication
- Secure file uploads if resumes are added
- Meeting URL validation
- Exam integrity

## Design principles

- Prefer least privilege by default.
- Separate authentication, authorization, and visibility rules clearly.
- Keep audit records for company access to student information.
- Treat exam results as privacy-sensitive data.

## Compliance direction

- Keep consent and auditability explicit in both design and later implementation.
- Ensure privacy decisions can be explained in reviews and incident analysis.
