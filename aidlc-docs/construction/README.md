# Construction docs

This folder contains unit-by-unit working documents used once the project moves from inception into structured construction.

## Unit expectations

Each unit folder should contain:

- `unit-state.md`
- `functional-design.md`
- `nfr-requirements.md`
- `nfr-design.md`
- `infrastructure-design.md`
- `code-generation.md`

Use `templates/unit` when creating new units.
