# Functional design: U0-2-user-personas-definition

## Purpose

Describe the representative users whose goals should drive product and workflow design.

## User story

As a team, we need realistic personas so the platform is designed around actual learner, recruiter, reviewer, and admin needs.

## Functional requirements

- Define learner personas.
- Define company-side personas.
- Define the platform admin persona.

## Inputs

- Product vision
- U0-1 requirements baseline

## Outputs

- Persona document with goals, pains, and expectations

## User flow

1. Identify core user groups.
2. Describe goals and constraints.
3. Use personas to inform later unit scope.

## Acceptance criteria

- Persona coverage matches the intended platform users.
- Each persona is useful for later unit planning.

## Out of scope

Detailed feature prioritization and implementation workflows.
