# NFR requirements: U0-4-technology-selection-and-architecture

## Security

Candidate stacks must support strong authentication, authorization, and auditability.

## Privacy

Technology choices must support consent-aware access control and secure data handling.

## Performance

Selection criteria should consider scaling for learning, exams, and matching workloads.

## Reliability

Architecture direction should support resilient operation across environments.

## Accessibility

Frontend candidates should be suitable for accessible user experiences.

## Maintainability

The chosen stack must fit unit-by-unit delivery and long-term support.
