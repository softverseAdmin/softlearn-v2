# NFR requirements: U1-1-project-initialization

## Security

Scripts should avoid destructive defaults and encourage safe review flow.

## Privacy

Repo guidance must keep student privacy visible even before app code exists.

## Performance

Checks and scripts should stay lightweight for fast contributor feedback.

## Reliability

Core repository structure should be consistently reproducible.

## Accessibility

Docs and scripts should use clear messaging and predictable conventions.

## Maintainability

Templates and docs should reduce duplicated manual setup across future units.
