# NFR requirements: U0-3-core-features-breakdown

## Security

Security and privacy work must appear explicitly in the unit map.

## Privacy

Privacy-sensitive units should be separated enough to review clearly.

## Performance

Roadmap structure should support incremental delivery without oversized units.

## Reliability

Unit naming and phasing should remain stable enough for planning continuity.

## Accessibility

User-facing units should leave room for accessibility requirements later.

## Maintainability

Units should be small, understandable, and traceable.
