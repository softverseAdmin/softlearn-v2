# Functional design: U0-3-core-features-breakdown

## Purpose

Provide a complete decomposed unit map so work can proceed in small, reviewable increments.

## User story

As a delivery team, we need a unit roadmap that covers the product from inception to operational hardening.

## Functional requirements

- Group work into phases.
- Name units clearly by outcome.
- Cover learning, exams, matching, hiring, privacy, admin, and platform quality.

## Inputs

- Requirements baseline
- Persona definitions

## Outputs

- Feature breakdown document
- Initial construction unit roadmap

## User flow

1. Group capabilities by domain.
2. Sequence units into phases.
3. Review for missing dependencies.

## Acceptance criteria

- The phase list is complete through Phase 19.
- Units are named clearly enough for later PR scoping.

## Out of scope

Exact implementation estimates or staffing plans.
