# NFR requirements: U0-6-ai-matching-strategy-design

## Security

Matching should only use data the platform is authorized to process.

## Privacy

Matching inputs and outputs must honor consent and visibility rules.

## Performance

The strategy should allow efficient matching later, even if the current unit is conceptual.

## Reliability

Matching rules should be deterministic enough to explain and audit.

## Accessibility

Explanations should be understandable to product and review stakeholders.

## Maintainability

The strategy should allow incremental sophistication without rewriting the whole model.
