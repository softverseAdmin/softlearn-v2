# Functional design: U0-6-ai-matching-strategy-design

## Purpose

Define how the platform will start matching students and companies in an explainable way.

## User story

As a platform team, we need a matching strategy that is useful early and remains auditable as intelligence grows.

## Functional requirements

- Start with rule-based matching.
- Include skill, course, exam, language, and location/work-style dimensions.
- Reserve vector and LLM enhancements for later phases.

## Inputs

- Requirements baseline
- Persona needs
- High-level data model

## Outputs

- AI matching strategy document

## User flow

1. Define explainable dimensions.
2. Describe initial scoring behavior.
3. Describe later enhancement path.

## Acceptance criteria

- Initial approach is explainable and auditable.
- Future AI additions do not become mandatory for MVP.

## Out of scope

Production scoring engine or model operations.
