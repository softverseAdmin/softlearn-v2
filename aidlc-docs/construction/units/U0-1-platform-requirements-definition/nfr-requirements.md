# NFR requirements: U0-1-platform-requirements-definition

## Security

Requirements must identify protected actions and sensitive data categories.

## Privacy

Student profile and exam visibility rules must be explicit from the start.

## Performance

This unit focuses on documentation responsiveness, not runtime targets.

## Reliability

Baseline documents must be versioned and reviewable.

## Accessibility

Requirements should account for accessible learning and job-search experiences later.

## Maintainability

Requirements should be structured so later units can trace back to them cleanly.
